## SEO Checklist for Every Post

- [ ] Primary keyword in: title, H1, first 100 words, URL slug, meta description
- [ ] Secondary keywords naturally distributed (2–4 per post)
- [ ] Internal links to: relevant service page, Calendly/contact CTA, 2 related blog posts
- [ ] Article Schema markup added
- [ ] Meta title under 60 characters
- [ ] Meta description under 160 characters, includes CTA verb
- [ ] Images with descriptive alt text
- [ ] Minimum 1,000 words (target 1,500–2,500 for competitive keywords)
- [ ] At least one original visual (chart, screenshot, or infographic)
- [ ] FAQ section for additional SERP features (People Also Ask)
