## Email Best Practices

### Sending Setup
- Use a warmed domain (not your main domain — use powerbiproagency.io or similar)
- Send limit: 30–50 cold emails/day to avoid spam flags
- Use personalization tokens properly — broken tokens kill conversion
- Send from a real name, not "Team PowerBI Pro"

### Subject Line Testing
Run A/B tests on these variations:

Curiosity:
- "Quick question about {Company}'s reporting"
- "How does {Company} handle monthly close?"

Specificity:
- "{Company}'s pipeline visibility"
- "Power BI for {Industry} companies like {Company}"

Result-led:
- "15 hours/week → 0 hours (what we did for [similar company])"
- "The dashboard that found €40K in hidden losses"

### Timing
- Best send days: Tuesday–Thursday
- Best send times: 8–9am or 2–3pm in recipient's timezone
- Avoid: Monday morning (inbox overload), Friday afternoon (pre-weekend)

### Tools (All Free/Low-Cost)
- **Apollo.io** (free tier): Lead sourcing by title, company size, industry
- **Hunter.io** (free tier): Email finding and verification
- **Lemlist or Instantly.ai**: Sequence automation with personalization
- **Loom**: Free video tool for personalized video emails (high reply rate)
